# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussion about the work. Harassment, personal attacks, and publishing
other people's private information are not accepted in issues, pull
requests, or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through
GitHub (Security → Report a vulnerability works for private contact) or the
contact details at <https://siddharthkumar.com>. Reports are handled in
confidence.

## Enforcement

The maintainer may edit or remove comments, commits and issues that break
these rules, and may block contributors who break them repeatedly, following
the enforcement guidelines of the Contributor Covenant 2.1.
